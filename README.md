# Income Calculator

Income Calculator is a personal C# application designed to help distribute income across customizable categories.

## Project Goal

The goal of this project is to create a simple tool where a user can enter their net income and automatically determine how that money should be distributed.

Categories can use either:

- **Fixed amounts** — a specific dollar amount is deducted first.
- **Percentages** — a percentage of the remaining income is distributed after all fixed amounts have been deducted.

## Planned Features

- Enter net income
- Create customizable distribution categories
- Add, edit, and remove categories
- Support fixed and percentage-based amounts
- Process fixed amounts before percentage distributions
- Prevent percentage categories from exceeding 100%
- Validate that fixed amounts do not exceed the entered income
- Save category settings between sessions
